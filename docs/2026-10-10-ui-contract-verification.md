# UI contract verification, 10 October 2026

## Baseline

An isolated subagent read the previous UI and UX skills. It found that canonical
project-standard discovery, growing-list placement, dialog-container breakpoints and
page-versus-filtered totals were not explicit requirements. The new UI policy test also
failed because the startup gate did not require UI contract discovery.

## Policy and adapter checks

After extending the existing UI skills and shared gate, `bash test/smoke.sh` passed all
manifest, skill, portability, hook, adapter and installer-preservation checks.
`bash test/ui-policy.sh` passed startup-policy and portable source checks. The doctrine
is carried by the same shared gate through the hook, native adapter and instruction
fallback; no second injected copy was created.

## Independent application

A fresh isolated subagent independently discovered a synthetic support repository's
instructions, UI contract version 7 and design version 3. It applied the local Tickets,
Assigned agent and Reply draft terms, preserved the exact approved heading, kept controls
above bounded lists, used container-based dialog columns, distinguished unknown from
Off, preserved retained drafts, prohibited automatic paid retries, exposed ownership
conflicts and required scoped totals. It selected the consuming project's 360px minimum
phone and its own four viewport requirements rather than imposing another project's
values. It explicitly separated source observations from untested runtime behavior.

## Fresh installed session

An ephemeral read-only session with normal plugin configuration discovered the installed
0.7.0 UI and UX skills without receiving their paths. Its tool transcript read both
skills and independently loaded the synthetic support project's instructions, contract
and design versions. Its proposal preserved the local approved heading, labels and
viewport requirements, applied the growing-list, ownership, retained-result and scoped
metric rules, and separated observed source from unverified runtime behavior.

The installer comparison preserved every unrelated installed plugin. Native installation
loaded the updated shared gate and skills; smoke tests also covered the instruction
fallback and hook adapters.

## Limits

Agent exercises verified policy discovery and a concrete read-only proposal in those
runs. They do not prove every future agent will comply or that any proposed application
works. Static checks protect policy wiring and known portability leaks; human review
still owns UX judgment. Product evidence and live workflow transcripts remain in their
consuming repositories, not this plugin.
